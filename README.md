# website-starter

Template für Kundenwebsites (Astro + Tailwind v4, statisch, Cloudflare Pages).

**Neues Kundenprojekt:**
```bash
gh repo create dein-studio/kunde-<name> --template dein-studio/website-starter --private --clone
cd kunde-<name> && claude
# → "Starte das Kunden-Onboarding für <Kunde>"
```

**Wichtig:** Dieses Template enthält bewusst KEIN Design. Fonts, Farben und
Layout entstehen pro Kunde über den design-konzept-Skill. Die Magenta-
Platzhalterfarbe in `src/styles/global.css` ist Absicht — sie schreit, bis
sie ersetzt wird.

Lokal: `npm install && npm run dev`
